# Aurexus Group Ltd Website

Official corporate website for **Aurexus Group Ltd** (`https://www.aurexus-group.com`).

## Stack

- Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · Framer Motion · next-themes
- Markdown content in `content/`, `legal/`, `seo/`, `footer/`
- Dark / light mode · WCAG-oriented UI · SEO (sitemap, robots, JSON-LD)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Content

| Path | Purpose |
|------|---------|
| `content/` | Page copy (home, about, industries, solutions, bioaegix, research, careers, contact, technology, trust) |
| `content/insights/` | News & insights articles |
| `legal/` | UK enterprise legal policies |
| `seo/metadata.md` | Default SEO notes |
| `footer/footer.md` | Footer registration & legal index |

Source of truth for messaging: Aurexus Corporate Book (Volume I). Do not invent unverified company facts.
